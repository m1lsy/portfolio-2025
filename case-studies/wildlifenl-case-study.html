WildlifeNL:
WildGids & WildRapport

Client

inMotionVR / GAMR

Timeline

February – June 2026

Role

UX/UI designer and Flutter developer

The Product

WildlifeNL is a pair of mobile applications for exploring wildlife and recording observations or incidents. During my internship, I worked on improving the interface and implementing those improvements in Flutter within an existing codebase.

The Challenge

The apps support different tasks, so the main challenge was making the important actions easier to find without treating both products as identical. WildGids needed to support map-based exploration, while WildRapport needed clear routes into different types of reports.

  • Make the primary actions easier to discover
  • Improve hierarchy and navigation across existing screens
  • Keep the experience consistent while respecting each app's purpose

My Work

I reviewed the existing applications, identified interface and navigation improvements, designed and refined the proposed changes in Figma, and implemented the front-end work in Flutter.

I collaborated with the development team through Git branches and reviews, balancing design decisions with the constraints of an existing product.

Outcome

The project resulted in clearer flows for exploring wildlife and creating reports, supported by a more consistent interface system. It strengthened my ability to work across UX, UI and implementation while contributing to a product that was already in use.

Key skills: UX/UI design, Figma, Flutter, Dart, Git and collaborative product development.
